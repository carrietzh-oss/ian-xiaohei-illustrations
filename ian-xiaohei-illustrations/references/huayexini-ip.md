# 花野稀泥 IP 角色圣经 v2.0

> 状态：用户已确认。本文档和两张用户确认图是后续出图、内容模板、周边和 GitHub Skill 的唯一视觉基准。

## 1. IP 定位

花野稀泥是一个冷脸萌、持续试错的视觉创意实验者，把普通素材、生活问题和奇怪想法变成意想不到的视觉结果。角色不是单一的 AI 工具吉祥物，而是必须参与解释图、场景或流程中核心动作的操作员。

## 2. 只允许两套形象

### A 无头套背袋版（`backpack`）

- 黑色短直 Bob 齐刘海完整露出，不戴头套。
- 透明紫粉色双结袋只背在肩膀/背部后方，袋内基本为空。
- 不得把袋子移到头顶、胸前、手里或改成肩包/挂袋。

### B 有头套版（`head-worn`）

- 黑色短直 Bob 齐刘海从袋子下沿露出。
- 透明紫粉色双结袋直接戴在头顶，恰好两个对称蝴蝶结；不得再背另一个袋子。
- 袋内只能有抽象奇思妙想符号：小灯泡、星星、纸条、问号等；不得有器官或写实生物组织。

## 3. 两版不可变共同识别点

- 使用用户确认图中的人物比例和轮廓；不额外 Q 版化、不拉长、不改成泛化卡通人物。
- 黑色短直 Bob 齐刘海、紫色椭圆墨镜、粉色泡泡糖、冷脸萌表情。
- 灰色宽松西装短裤套装、白色衬衣、领带、腰带。
- 紫色、白色、黑色相间的鞋子。
- 胸口画面右侧固定徽章：黑色小猫 + 蓝色星形底 + 恰好四条橙色小鱼。
- 默认纯白背景、花野稀泥/小黑式白底、黑色细手绘线稿、干净留白、克制荒诞隐喻。

动作、道具、场景、画幅、标签和表情强度可以随内容变化；以上人物身份不能随意变化。只有用户明确重新确认，才允许修改核心设定。

## 4. 徽章规则

胸口徽章必须保持黑猫、蓝色星形底和恰好四条橙色鱼的组合，位置在画面右侧胸口，尺寸小而清楚。独立徽章图只作为局部参考，不得重新设计成另一套徽章；禁止额外鱼、其他动物、三个点、枪形徽章、文字或品牌水印。

## 5. 固定色彩与表现

- 袋子和墨镜：紫粉、浅丁香高光，保持半透明塑料感。
- 服装：中性灰，不漂移成灰紫套装、纯黑套装或其他颜色。
- 领带、鞋子和线稿可以使用紫色；鞋子始终保持紫/白/黑三色关系。
- 徽章集中使用蓝橙对比；其余画面只使用少量红、橙、蓝色强调。
- 推荐彩铅、蜡笔、马克笔混合质感；线条手绘、略有不规则感，背景纯白且保留大量留白。

## 6. 生成前确认门

1. 用户明确说 A、无头套背袋版、袋子版、背袋版时，选择 `backpack`。
2. 用户明确说 B、有头套版、头套版时，选择 `head-worn`。
3. 用户只说“用我的 IP”或没有明确变体时，必须先问：**“这次使用哪一套形象：A 无头套背袋版，还是 B 有头套版？”** 不得根据动作、场景、画幅或模型习惯自动选择。
4. 用户要求两版时，分开生成；每组固定一个变体，不在同一画面或同一组内混用。
5. 每次 imagegen/image_edit 前，内部记录 `selected_variant` 和对应参考路径；中途不得切换。
