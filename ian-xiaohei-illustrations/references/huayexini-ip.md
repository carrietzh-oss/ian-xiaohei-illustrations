# 花野稀泥 IP 角色圣经 v1.0

> 状态：已确定，可作为后续出图、内容模板、周边和 GitHub Skill 的唯一视觉基准。

## 1. IP 一句话

一个固定使用背袋版或头套版紫色“双结脑洞袋”形象、表情冷淡却很可爱的创意实验者，把普通素材、生活和奇怪想法变成意想不到的视觉作品。

## 2. 品牌定位

- 名称：花野稀泥
- 内容方向：AI × 视觉创意实验
- 人物身份：创意实验者，不是单一的 AI 工具吉祥物
- 核心母题：普通素材/真实问题 → 奇怪想法 → AI、剪辑或摄影工具 → 明显的视觉结果
- 整体气质：温暖治愈、活泼有梗、极简高级，带一点“邪修”和持续试错感
- 角色关键词：冷脸萌、好奇、爱折腾、克制、意外、实验感

## 3. 角色外貌定稿

### 必须保持

1. 大头短身的 Q 版创作者比例，轮廓简洁，缩小后仍然清楚。
2. 短直黑色 Bob 发；背袋版完整露出头发，头套版从头套下沿两侧露出。
3. 半透明紫粉色塑料脑洞袋固定有两种佩戴方式：背袋版背在身后，头套版直接套在头顶；两版都保留左右各一个、合计两个对称扎结。
4. 紫色椭圆墨镜；不戴墨镜版本要保留同样的眼型和冷淡气质。
5. 粉色泡泡糖，作为主要识别动作之一。
6. 灰紫色剪裁感创作者套装、深葡萄紫腰封、宽腿短裤/短阔腿裤、深色鞋。
7. 角色表情以“冷脸萌”为核心：半垂眼、微抿嘴、淡淡腮红，不能默认变成大笑或夸张卖萌。
8. 画面右侧胸口佩戴最终徽章：黑色小猫、蓝色异形星形底、四条橙色小鱼。

### 徽章定稿

胸口徽章采用用户提供的“黑猫四鱼蓝色星形”图形，并适配为小尺寸珐琅/贴纸徽章：

- 中心：黑色小猫咪头像，保留大白眼圈和浅色胡须
- 底形：亮蓝色不规则星形/水花形
- 环绕：恰好四条橙色小鱼
- 外轮廓：深蓝描边，必要时加奶油白外边
- 位置：角色胸口画面右侧
- 尺寸：小而清楚，不遮挡衣领、腰封和口袋
- 禁止：三个点、枪形徽章、其他动物、额外鱼、文字、字母和品牌水印

独立徽章素材可以比胸口版本更大，但构图必须保持一致，不能重新设计成另一套图形。

## 4. 固定配色

### 角色主色

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 脑洞袋、墨镜边框 | `#C96BD8` | 主紫/兰花紫 |
| 高光、透明袋反光 | `#E7C8F0` | 浅丁香紫 |
| 皮肤、奶油白区域 | `#F7EDE2` | 暖奶油白 |
| 腮红、泡泡糖 | `#F2B2BB` | 柔和粉色 |
| 套装 | `#B8B4C2` | 雾灰紫 |
| 线稿、腰封、鞋 | `#43233F` | 深葡萄紫，避免纯黑线稿 |
| 灵感火花点缀 | `#A7E3C1` | 薄荷绿，少量使用 |

### 徽章辅助色

徽章允许使用以下辅助色，但不能改变角色主色系统：

- 蓝色星形底：明亮钴蓝/湖蓝
- 小鱼：橙金色
- 徽章外边：奶油白和深海军蓝

徽章的蓝橙对比是识别点，使用面积集中在胸口徽章和独立徽章素材中。

## 5. 画风规则

### 推荐表现

- 手绘彩铅、蜡笔和马克笔混合质感
- 深葡萄紫或深海军蓝线稿
- 轮廓清楚，局部保留手绘不规则感
- 色块明快，但整体留白干净
- 适合拼贴、手写字、杂志排版和人物抠图
- 表情克制，笑点来自动作、道具和场景反差

### 不推荐表现

- 写实人像、厚重 3D、普通二次元美少女模板
- 过度甜美、闪亮眼睛、夸张大笑
- 随机改变脑洞袋颜色或扎结数量
- 纯黑粗线覆盖全部细节
- 随机添加武器、文字、品牌 Logo 或不相关装饰
- 把角色画成普通猫咪、普通吉祥物或没有创作者服装的泛化人物

## 7. 通用生成 Prompt

### 基础 Prompt

```text
生成“花野稀泥”官方 IP 角色：冷脸萌的 Q 版创意实验者。
角色必须保持：短直黑色 Bob 发、半透明紫粉色塑料脑洞袋、所选变体的左右两个对称扎结、紫色椭圆墨镜、粉色泡泡糖、灰紫色剪裁感创作者套装、深葡萄紫腰封、宽腿短裤和深色鞋。
角色胸口画面右侧佩戴最终徽章：黑色小猫头像、亮蓝色不规则星形底、四条橙色小鱼，做成小尺寸珐琅/贴纸徽章。
表情保持半垂眼、微抿嘴、淡淡腮红的冷脸萌气质；动作和场景可以变化，但人物身份、轮廓、服装、脑洞袋和徽章不能变化。
使用手绘彩铅、蜡笔和马克笔混合质感，深葡萄紫线稿，干净留白，适合拼贴和杂志排版。
```

### 变量区

每次只替换以下变量中的一到两个，不要同时改变人物核心设定：

```text
动作：[填写动作]
场景：[填写场景]
道具：[填写道具]
情绪：[冷静/好奇/轻微惊讶/克制开心/疲惫无语/轻微得意]
画面用途：[小红书封面/漫画/贴纸/拼豆/头像/视频贴图]
构图：[正面/45度/侧面/全身/半身/2×3表情网格]
```

### 统一负面 Prompt

```text
不要改变角色脸型、发型、所选脑洞袋变体、扎结数量、墨镜、泡泡糖、服装、腰封和胸口徽章；不要同时出现背袋版和头套版；不要三个点、不要枪形徽章、不要额外鱼、不要额外动物、不要武器、不要文字、不要水印、不要 Logo、不要多余角色、不要过度甜美、不要写实风、不要随机换色。
```

## 8. 常用变体 Prompt

### 漫画版

```text
以花野稀泥官方 IP 角色为主角，制作 3 格或 4 格短漫画。每格保持同一角色外貌、冷脸萌表情基底、紫色双结脑洞袋、灰紫创作者套装和黑猫四鱼蓝色星形胸口徽章。笑点来自一本正经的冷脸和离谱的创意实验结果。画面使用手绘彩铅、拼贴碎片、少量手写拟声词；如未提供文字，不要自行生成文字。
```

### 拼豆版

```text
把花野稀泥官方 IP 角色转换成可制作的拼豆像素图。保留紫色双结脑洞袋、黑色短发、灰紫套装、深葡萄紫腰封和黑猫四鱼蓝色星形徽章。使用有限色块、清楚网格、硬边轮廓和高对比配色；不要渐变、毛发纹理、复杂阴影或不可辨识的小细节。输出正面、居中、适合 32×32 到 64×64 豆子的设计。
```

### 贴纸版

```text
把花野稀泥官方 IP 角色制作成一张可裁切的透明背景贴纸。保留冷脸萌、紫色双结脑洞袋、泡泡糖、灰紫创作者套装和黑猫四鱼蓝色星形胸口徽章。外轮廓使用干净的奶油白描边，内部保留手绘彩铅纹理，动作夸张一点但脸部仍然冷淡。不要背景、不要文字、不要水印。
```

### 小红书封面版

```text
制作一张适合小红书的花野稀泥风格封面：真实素材切片与花野稀泥冷脸萌 IP 角色进行拼贴，使用紫灰主色、少量蓝橙徽章色和奶油白留白。角色作为视觉锚点，标题区域留出清晰空白；整体像实验杂志，而不是普通卡通海报。除非提供准确文案，否则不要生成文字。
```

## 9. 出图验收清单

每张新图发布或纳入素材包前检查：

- 角色一眼仍是花野稀泥，而不是泛化猫咪或泛化女孩
- 脑洞袋是紫粉半透明材质，并有两个扎结
- 表情仍然冷脸萌，不因场景变化而失控
- 灰紫创作者服装和深葡萄紫腰封仍然存在
- 胸口画面右侧是黑猫、蓝色星形和四条橙色小鱼徽章
- 主色没有漂移成另一套颜色
- 透明背景版本没有白底、阴影或光晕
- 拼豆版没有过多渐变和无法制作的细碎纹理
- 小红书封面在缩略图尺寸下仍能看见角色轮廓和徽章

## 11. 双形象变体（不可变）

花野稀泥固定保留两套合法形象，生成前必须选择其中一个：

### A. 背袋版（backpack）

- 半透明紫粉色脑洞袋背在身后，位于肩膀/背部后方。
- 袋体左右各一个、合计两个对称紫色扎结/蝴蝶结；头顶和短直黑 Bob 发保持可见。
- 适合全身站立、出门、移动、携带工具或“背着想法上路”的构图。

### B. 头套版（head-worn）

- 半透明紫粉色脑洞袋直接套在头顶，像帽子/头套，沿头部两侧包住头发。
- 左右各一个、合计两个对称扎结；它不是背包、肩包、挂袋或手提袋。
- 适合坐在桌前、学习、思考、教程、电脑操作和近景脑洞场景。

### 选择与连续性

- 用户明确说“背着、背袋、背包、出门、全身移动”时使用背袋版。
- 用户明确说“头套、套在头上、戴在头顶”时使用头套版。
- 用户没有指定时，移动/全身优先背袋版；桌前/学习/教程/近景优先头套版，并在出图前说明选择。
- 同一张图、同一组连续分镜和同一套素材只能使用一个变体；除非用户明确要求切换，否则不改变袋子的位置。
- 不得把两个变体混合成“头上一个、背后一个”的第三种形象。
