# 花野稀泥手绘插画 Skill

本 skill 保留 `ian-xiaohei-illustrations` 的文章理解、认知锚点、shot list、原创隐喻、单图生成、QA 与交付工作流；角色身份已按用户确认图一比一替换，并且当前只允许 A、B 两套形象。

## 唯一 IP 锁定

- A「无头套背袋版」：黑色短直 Bob 齐刘海，透明紫粉袋背在身后，袋内基本为空。
- B「有头套版」：同样的黑色短直 Bob 齐刘海，透明紫粉袋直接戴在头上，袋内只能有灯泡、星星、纸条、问号等抽象奇思妙想符号。
- 两版固定保留：灰色宽松西装短裤、白色衬衣、领带、腰带、紫色椭圆墨镜、粉色泡泡糖、紫白黑相间的鞋子，以及胸前黑猫 + 蓝色星形 + 恰好四条橙色鱼徽章。
- 默认纯白背景、黑色细手绘线稿和荒诞隐喻；禁止灰发、耳饰、长裤、器官元素、第三种形象、额外动物或额外徽章。

生成前若用户没有明确说 A、B 或“两版”，必须先询问选择；不得根据场景自动猜测。若要求两版，分开生成，不能在同一画面或同一组内混用。

默认风格是纯白留白、黑色细手绘线条和少量红/橙/蓝标签。用户明确要求安装/教程流程时，允许使用 3–5 格连续手绘分镜；每格一个核心动作，角色始终参与动作。

先读 [`SKILL.md`](SKILL.md)，再按需读取 `references/` 中的双形象角色、风格、构图、Prompt 与 QA 规则。角色身份只能读取 `assets/standard-sheet/` 内的两张用户确认图；旧角色图和原小黑人物图已从当前资产中清除。
