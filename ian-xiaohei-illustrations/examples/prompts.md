# 示例 Prompts

## 文章理解与 shot list

```text
请先阅读下面的文章，不要立即画图：
1. 用一句话说明文章主张；
2. 提取 4–8 个认知锚点；
3. 为每个锚点给出原创视觉隐喻、构图类型和花野稀泥的核心动作；
4. 生成一个可执行的 shot list，并标注哪些画面适合横版 16:9。
```

## 单张文章配图

```text
根据第 3 个认知锚点生成一张 16:9 文章配图。保持纯白背景、黑色细手绘线条、大面积留白和少量红橙蓝强调色。选择背袋版：紫粉色脑洞袋背在身后，左右两个对称结；花野稀泥必须参与核心动作，保持灰色套装和胸前黑猫 + 蓝色不规则星形 + 四条橙色鱼徽章。
```

## 教程/安装流程分镜

```text
把“去 GitHub 下载文件 → 去 Obsidian 安装插件并获取 API → 去 Chrome 安装插件 → 在 Chrome 插件中匹配同一个 API”画成 4 格连续手绘教程，画布 2560×1440。

每格只表现一个核心动作，步骤文字短而清晰；使用原创手绘隐喻，不做普通商业 PPT。选择并固定头套版：紫粉色脑洞袋直接罩在头顶、左右各一个对称结、紫色椭圆墨镜、粉色泡泡糖、灰色套装、黑猫蓝星四鱼徽章。
```

## 局部修正

```text
只编辑角色识别：把当前角色固定为背袋版或头套版中的一个。若选择头套版，让脑洞袋直接套在头顶；若选择背袋版，让袋体位于背后。两版都保留左右两个对称扎结。不要改变灰色套装、墨镜、泡泡糖、动作、构图、文字或黑猫四鱼徽章。
```

## 社交封面

```text
为这篇文章生成一张 16:9 社交媒体封面。标题区域保持干净，花野稀泥在画面中完成一个能表达文章主张的荒诞动作。选择一个并固定：背袋版或头套版。保持纯白手绘风、灰色套装和紫色双结脑洞袋；不要做成过度商业化的海报。
```
