# 示例 Prompts

## 文章理解与 shot list

```text
请先阅读下面的文章，不要立即画图：
1. 用一句话说明文章主张；
2. 提取 4–8 个认知锚点；
3. 为每个锚点给出原创视觉隐喻、构图类型和花野稀泥的核心动作；
4. 生成一个可执行的 shot list，并标注哪些画面适合横版 16:9。
```

## 单张文章配图

```text
根据第 3 个认知锚点生成一张 16:9 文章配图。保持纯白背景、黑色细手绘线条、大面积留白和少量红橙蓝强调色。选择 A 无头套背袋版：透明紫粉袋背在身后且袋内基本为空；花野稀泥必须参与核心动作，保持灰色西装短裤、白色衬衣、领带、腰带、紫色墨镜、粉色泡泡糖、紫白黑鞋子和胸前黑猫 + 蓝星 + 四条橙鱼徽章。
```

## 教程/安装流程分镜

```text
把“去 GitHub 下载文件 → 去 Obsidian 安装插件并获取 API → 去 Chrome 安装插件 → 在 Chrome 插件中匹配同一个 API”画成 4 格连续手绘教程，画布 2560×1440。

每格只表现一个核心动作，步骤文字短而清晰；使用原创手绘隐喻，不做普通商业 PPT。选择并固定 B 有头套版：透明紫粉袋直接戴在头顶，袋内只有灯泡、星星、纸条等抽象符号；保持黑发、灰色西装短裤、白衬衣、领带、腰带、紫色墨镜、粉色泡泡糖、紫白黑鞋子和黑猫蓝星四鱼徽章。
```

## 局部修正

```text
只编辑角色识别：把当前角色固定为 A 无头套背袋版或 B 有头套版。A 的袋体只能位于背后且基本为空；B 的袋体只能位于头顶且只含抽象奇思妙想符号。不要改变黑色发型、灰色西装短裤、白衬衣、领带、腰带、墨镜、泡泡糖、紫白黑鞋子、动作、构图、文字或黑猫四鱼徽章。
```

## 社交封面

```text
为这篇文章生成一张 16:9 社交媒体封面。标题区域保持干净，花野稀泥在画面中完成一个能表达文章主张的荒诞动作。先明确选择 A 无头套背袋版或 B 有头套版并固定；保持纯白手绘风和全部固定识别点，不要做成过度商业化的海报。
```
