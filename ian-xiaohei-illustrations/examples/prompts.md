# 花野稀泥 Skill 示例 Prompt

## 小红书封面

```text
使用 huayexini-illustrations Skill，生成一张 4:5 小红书封面。
主题：我用 AI 把普通照片变成意外的视觉作品。
构图：左侧是普通照片的纸质切片，右侧是花野稀泥冷脸萌角色在操作灵感方块，中间有拼贴胶带和少量手绘线条，顶部和左上方留出标题区。
保持紫色双结脑洞袋、灰紫创作者套装、泡泡糖和黑猫四鱼蓝色星形徽章。
不要自动生成标题文字。
```

## 四格漫画

```text
使用 huayexini-illustrations Skill，生成 4 格冷脸萌短漫画，比例 4:5。
主题：三分钟热度的人如何把一个奇怪想法做完。
节奏：想法突然出现 → 立刻开始尝试 → 中途失控 → 意外得到一个可发布的结果。
花野稀泥角色始终保持同一外貌、服装、脑洞袋和黑猫四鱼蓝色星形徽章；每格只改变动作，不要大段文字。
```

## 拼豆版

```text
使用 huayexini-illustrations Skill，把花野稀泥角色转换成 32×32 到 64×64 的拼豆像素图。
正面、居中、有限色块、高对比边缘；保留紫色双结脑洞袋、灰紫套装、泡泡糖和黑猫四鱼蓝色星形徽章。
不要渐变、毛发细节、复杂阴影或小字。
```

## 创意实验插画

```text
使用 huayexini-illustrations Skill，生成一张 16:9 文章插画。
主题：普通素材经过 AI 和剪辑后，变成完全没想到的视觉结果。
让花野稀泥角色在画面中央执行一个明确的荒诞动作，背景干净留白，使用手绘彩铅、紫灰主色和少量蓝橙徽章色。
不要做成 PPT 流程图，不要标题，不要长文字。
```

## 已选衍生资产复现方向

```text

花野稀泥先面对空白画板，再摆放灵感方块、马克笔和相机，最后完成一张抽象拼贴并盖章确认。
保持冷脸萌、紫色双结脑洞袋、泡泡糖、灰紫套装和黑猫四鱼徽章；不生成可读文字。
```

```text
使用 huayexini-illustrations Skill，把花野稀泥做成约 64×64 的全身拼豆像素图。
使用有限固定配色、清晰方格和可制作的平面色块；保留双结脑洞袋、墨镜、泡泡糖、灰紫套装和黑猫四鱼徽章。
```

