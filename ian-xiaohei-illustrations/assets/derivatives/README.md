## 固定规则

- 保持冷脸萌、短黑发、紫粉半透明双结脑洞袋、粉色泡泡糖和灰紫创作者套装。
- 胸前徽章固定为黑猫 + 钴蓝色不规则星芒底 + 恰好四条橙色小鱼。
- 不恢复三个点，不使用枪徽章，不添加其他动物或大段自动生成文字。
- `06-sticker-cube-marker.png` 保留透明背景，可直接作为贴纸切图参考。
