| 文件 | 用途 |
| --- | --- |
| `01-front.png` | 正面基准（戴墨镜） |
| `02-45-degree.png` | 45° 转面 |
| `03-side.png` | 侧面 |
| `04-back.png` | 背面 |

## 不可变识别点

- 黑色短直发、半透明薰衣草紫双结脑洞袋、粉紫椭圆墨镜、粉色泡泡糖。
- 灰紫创作者套装、深梅色腰封、宽腿短裤与深色鞋。
- 胸前固定徽章：黑猫 + 钴蓝色不规则星芒底 + 恰好四条橙色小鱼。
- 禁止恢复三个点、枪徽章、额外鱼、其他动物或新增文字。
